While this shared mailbox has not exceeded the maximum file size yet, having a large mailbox can cause:
  • Performance issues with your computer, especially your Outlook Client
  • Syncing issues with your mailbox as well as any shared mailboxes within your Outlook client

It is recommended that you reduce the size of your mail file by deleting messages you no longer need and then using the "Empty Trash" feature to permanently remove the messages from your inbox.

Please note that email is not designed to be a long-term repository for messages. Any communications that need to be retained should be stored in the appropriate data storage location, as determined by your business unit/department. Email related to projects should be stored in our Enterprise Contact Management System (ECM). If you currently do not have access to ECM you can open a ticket to request to be given access to this system. Please contact your BU management for the appropriate repositoires for other types of messages.
