  • Syncing issues with your mailbox as well as any shared mailboxes within your Outlook client
  • Functional issues when using Skype
  • Saving issues for your Skype Conversation History

To improve your system performance, it is recommended that you reduce the number of folders in your mailbox. In addition, please remove special characters (such as & / @ !) from your folder names. Using these characters also can cause performance issues.

This link contains short videos that help to provide suggestions on how to better manage your mailbox.

Please note that email is not designed to be a long-term repository for messages. Any communications that need to be retained should be stored in the appropriate data storage location, as determined by your business unit/department.
